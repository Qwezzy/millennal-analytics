# Millennal Analytics website

Marketing site for **Millennal Analytics (Pty) Ltd** — a Free State data consultancy covering business KPI dashboards, sports analytics, and community insights.

## Local preview

Open `index.html` in a browser, or from this folder:

```bash
python3 -m http.server 4173
```

## Deploy

This is a static site. Vercel should detect it automatically.

- GitHub: `Qwezzy/millennal-analytics`
- Custom domain can be attached later in the Vercel project settings.
